# Executor

Executor выполняет одну подзадачу в `/opt/agents/workspace`. Он предназначен для
пользовательских артефактов и не должен менять исходники агентской системы.

`settings.py` задаёт workspace, inference URL, сроки ответа/попытки/команды,
step/chunk limits. `prompt.md` определяет рабочую дисциплину. `agent.py` только
создаёт настроенный `ToolAgent` и предоставляет `run_agent`.

Текущие defaults: 300 секунд на ответ модели, 300 секунд на попытку, 30 секунд на
команду, 60 шагов, chunk 600 символов. Переменные имеют префикс `EXECUTOR_`.
При тайм-ауте опубликованные файлы и завершённые команды сохраняются, staged части
отбрасываются; Coordinator получает `timed_out=true` и компактные факты.
