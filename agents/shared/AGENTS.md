# Shared agent runtime

`protocol.py` отправляет ограниченные запросы в OpenAI-compatible llama.cpp API,
проверяет `finish_reason`, JSON и ошибки транспорта. Он не читает environment:
`TransportSettings` передаёт агент-владелец.

`runtime.py` реализует `ToolAgent` и состояние одной попытки. Поддерживаются
`write_file`, `read_file`, `list_files`, `run_command`, `finish`. Запись собирается
в памяти по offset и публикуется атомарно через временный файл и `os.replace`.
Файловые инструменты не выходят за настроенный root и не проходят через symlink.
Командный инструмент запускается shell от пользователя процесса и потому следует
операционным правам из корневого `AGENTS.md`.

Runtime ограничивает размеры задач, chunk/staging, вывод команд, число шагов,
время команды, ответа модели и всей попытки. По окончании убивается группа процессов
команды. Success требует хотя бы одного фактического инструмента, отсутствия
незавершённых записей и неисправленных ошибок. Сырые ответы модели и полный вывод
не должны попадать через границу агентов.

Изменения runtime проверяй тестами атомарной записи, traversal/symlink, тайм-аутов,
ограничения вывода, protocol errors и ложного success.
