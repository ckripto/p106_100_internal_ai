# Developer

Developer дорабатывает проект `/opt/agents` силами локальной модели. Его root —
корень проекта; файловые инструменты могут читать и менять проект, а shell может
запускать тесты, устанавливать пакеты, обращаться по SSH и управлять сервисами в
рамках разрешений корневого `AGENTS.md`.

В системный контекст при старте загружаются корневой `AGENTS.md`, игнорируемый
`AGENTS.local.md` при его наличии и этот файл.
Перед изменением другого модуля Developer обязан прочитать ближайший
локальный `AGENTS.md` через `read_file`. Так он применяет ту же иерархию инструкций,
что основной coding agent, не переполняя 4096-токенный контекст всеми документами
сразу.

`settings.py` владеет всеми лимитами Developer. Defaults рассчитаны на рефакторинг:
300 секунд на ответ модели, 300 секунд на попытку, 120 секунд на команду, 100 шагов,
chunk 1000 символов, task 1200 символов и output 700 токенов. Из листинга исключены `.git`, caches, `data` и `venv`; прямое
чтение конкретного допустимого пути остаётся доступным.

Developer должен сохранить чужие изменения, читать файлы до правки, поддерживать
локальные AGENTS.md, запускать релевантные проверки и проверять сервис после
изменений. Историю разовых работ в AGENTS.md не записывать.
